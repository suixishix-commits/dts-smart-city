# 场景图层与配置清单

## 代码创建的场景对象（进入模块时创建，离开时删除）

| 模块 | 图层 key | 类型 | id 规则 | groupId |
|------|----------|------|---------|---------|
| 城市总览 | district | polygon | `district-<片区id>` | sc_district |
| 城市总览 | heat | heatmap | `population-heat` | sc_heat |
| 城市总览 | hotspot | marker | `hotspot-<事件id>` | sc_hotspot |
| 城市总览 | camera | marker | `camera-<摄像头id>` | sc_camera |

图层处于隐藏状态时不会创建对象，显示时才创建。

## 代码依赖的 ACP 图层

目前没有。后续模块（如城市生命线的地下模式）需要按图层名控制显隐时，在这里登记图层名，并与场景同事对齐。

## 运行时配置

| 文件 | 内容 |
|------|------|
| `public/config/dev.js` / `prod.js` | DTS Cloud 地址、工程 Id |
| `public/config/smart-city.js` | 各模块相机位、热力图垂直范围 |
| `public/data/smart-city/overview.json` | 总览 mock 数据（坐标为 WGS84 经纬度） |
