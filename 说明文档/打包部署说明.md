# 一、打包

1、开发服务器：npm run build:dev
2、生产服务器：npm run build:prod
3、Mock版本:npm run build:demo

# 二、配置

1、根据打包类型，修改public/config/下对应的dev.js、prod.js、fd.js配置文件
1）、dtsCloud.player。cloud IP地址与端口
2）、dtsCloud.pid。ACP工程ID
3）、dtsCloud.popupRootUrl。弹窗地址前缀。务必确保在cloud机器上能访问弹窗地址。
4）、dtsCloud.Path。Cloud安装目录
5）、dtsCloud.resourcePath。Cloud文件资源指定的路径
6）、finiteElement。有限元dat文件所在目录及http访问路径。

2、确认index.html中ac.min.js路径是否正确，不正确务必修改。

3、将打包后的dts_server_file/sdk文件夹下的所有内容复制到cloud机器上sdk目录下。也可以放在nginx下，确保资源能在Cloud机器上通过http访问即可

4、将打包后的dts_server_file/resource文件夹下的所有内容（一般有Marker图标，pak资源，通过@Path访问的资源）复制到cloud机器上文件资源目录下。
